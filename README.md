# Chord Explorer Pro

A professional tablature editor and chord exploration tool built by RParagon.

## Project Info

**URL**: https://github.com/RParagon/chord-explorer-pro.git

## Development

To get started with development:

1. Clone the repository
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS- Lucide React
